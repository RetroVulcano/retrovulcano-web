# Privacidad y recursos externos

- No se incluyen Google Fonts ni otras bibliotecas de terceros.
- No hay Google Analytics, Matomo, Meta Pixel, Hotjar ni otros scripts de analítica/rastreo.
- No se crean cookies mediante JavaScript.
- No se usa localStorage ni sessionStorage.
- Las imágenes, SVG, CSS y JavaScript de la web se sirven desde el propio sitio.
- Los enlaces a Bluesky, Mastodon, openSUSE, OrbeAutomata y Pulsa y Juega son enlaces externos normales: el navegador solo accede a esos sitios si el visitante pulsa el enlace.
- Los enlaces externos se abren con `noopener`; Mastodon conserva `rel="me"` para la verificación de identidad del perfil.
